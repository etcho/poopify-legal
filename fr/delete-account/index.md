# Poopify - Supprimer votre compte et vos données de Synchronisation cloud

**Application :** Poopify (Android) · **Développeur :** Everton Carvalho Leite

Poopify fonctionne sans compte. Un compte n'existe que si vous avez activé la fonctionnalité facultative de **Synchronisation cloud**, en vous connectant avec votre compte Google. Cette page explique comment supprimer ce compte et les données stockées dans le cloud.

## Option 1 : dans l'Application (la plus rapide)

1. Ouvrez Poopify et ouvrez le menu.
2. Touchez **Confidentialité**.
3. Touchez **Supprimer un compte de Synchronisation cloud**, confirmez, puis choisissez le compte Google utilisé pour la Synchronisation cloud.

Cela fonctionne même si la Synchronisation cloud est désactivée sur ce téléphone. Votre compte de Synchronisation cloud et toutes vos données stockées dans le cloud sont supprimés immédiatement. Les enregistrements de votre téléphone ne sont pas concernés.

Cette option apparaît sur les téléphones où la Synchronisation cloud est disponible ou a été utilisée. Si vous ne la voyez pas, utilisez l'Option 2.

Lorsque la Synchronisation cloud est activée, Menu > Synchronisation cloud propose aussi **Supprimer le compte et les données du cloud**, **Désactiver la Synchronisation cloud** (pour arrêter la synchronisation en gardant la copie dans le cloud) et **Désactiver et supprimer les données du cloud**.

## Option 2 : par e-mail (si vous n'avez plus l'Application ou le téléphone)

Envoyez un e-mail à **poopify.dev@gmail.com** :

- depuis la **même adresse e-mail** que le compte Google utilisé pour la Synchronisation cloud (afin que nous puissions vérifier que la demande vient de vous) ;
- avec l'objet **« Delete my Poopify account »**.

Nous supprimerons votre compte et vos données du cloud et vous répondrons pour le confirmer, sous 15 jours.

## Ce qui est supprimé

- Votre compte de Synchronisation cloud (le lien entre Poopify et votre compte Google).
- Tous vos enregistrements stockés dans le cloud : selles, enregistrements de menstruation, notes et profils.
- La preuve de votre consentement à la Synchronisation cloud.

Les données supprimées de nos systèmes actifs sont effacées immédiatement. Les copies résiduelles dans les systèmes de sauvegarde de Google Cloud sont supprimées dans les délais fixés par les conditions de suppression des données de Google Cloud.

## Ce qui n'est pas supprimé

- **Les enregistrements de vos appareils.** Supprimer le compte cloud n'efface jamais les données de votre téléphone. Pour les effacer aussi, utilisez **Effacer toutes les données** dans le menu de l'Application, ou désinstallez l'Application.
- **Votre compte Google** lui-même, qui est géré par Google.
- **Les statistiques d'utilisation et les rapports de plantage** (Google Analytics pour Firebase et Crashlytics). Ils ne contiennent ni vos enregistrements ni votre e-mail, et expirent d'eux-mêmes : 2 mois pour les événements d'utilisation, 14 mois pour les données d'utilisation au niveau de l'utilisateur et 90 jours pour les rapports de plantage.
- **Notre échange d'e-mails**, si vous nous avez écrit. Il est conservé comme trace de la demande jusqu'à ce que vous nous demandiez de le supprimer.
