# Poopify - クラウド同期のアカウントとデータの削除

**アプリ:** Poopify(Android)· **開発者:** Everton Carvalho Leite

Poopify はアカウントなしで使えます。アカウントが存在するのは、Google アカウントでログインして任意の**クラウド同期**機能をオンにした場合のみです。このページでは、そのアカウントとクラウドに保存されているデータを削除する方法を説明します。

## 方法 1: 本アプリで行う(最も簡単)

1. Poopify を開き、メニューを開きます。
2. **プライバシー**をタップします。
3. **クラウド同期のアカウントを削除**をタップし、確認したうえで、クラウド同期に使った Google アカウントを選びます。

このスマートフォンでクラウド同期がオフになっていても使えます。クラウド同期のアカウントとクラウド上のすべてのデータは直ちに削除されます。スマートフォン上の記録には影響しません。

この項目は、クラウド同期が利用可能な、または利用したことのあるスマートフォンに表示されます。表示されない場合は、方法 2 をご利用ください。

クラウド同期がオンのときは、メニュー > クラウド同期 にも**クラウドのアカウントとデータを削除**、**クラウド同期をオフにする**(同期を止めてクラウドのコピーを残す)、**オフにしてクラウドのデータを削除**があります。

## 方法 2: メールで行う(本アプリやスマートフォンがもうない場合)

**poopify.dev@gmail.com** に次の条件でメールを送ってください。

- クラウド同期に使った Google アカウントと**同じメールアドレスから**送信する(請求がご本人からのものであることを確認するため)
- 件名を **「Delete my Poopify account」** にする

アカウントとクラウドデータを削除し、15日以内に確認のご連絡をします。

## 削除されるもの

- クラウド同期のアカウント(Poopify と Google アカウントの紐付け)
- クラウド上のすべての記録: 排便、月経の記録、メモ、プロフィール
- クラウド同期への同意の記録

本番システムから削除されたデータは直ちに削除されます。Google Cloud のバックアップシステムに残るコピーは、Google Cloud のデータ削除規約で定められた期間内に削除されます。

## 削除されないもの

- **端末上の記録。** クラウドのアカウントを削除しても、スマートフォン上のデータが消えることはありません。それも消去するには、本アプリのメニューの**すべてのデータを消去する**を使うか、本アプリをアンインストールしてください。
- **Google アカウントそのもの**(Google が管理しています)。
- **利用統計とクラッシュレポート**(Google Analytics for Firebase と Crashlytics)。記録やメールアドレスは含まれず、自動的に削除されます: 利用イベントは2か月後、ユーザー単位の利用データは14か月後、クラッシュレポートは90日後。
- **私たちとのやり取り**(お問い合わせいただいた場合)。削除を求められるまで、請求の記録として保管します。
